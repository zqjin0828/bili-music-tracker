# v1.3.2 — 调试面板重做：把「为什么不计数」说清楚

## 这个版本解决什么问题

旧调试面板只有 `累计 / 状态 / 判定 / 会话` 四行。一旦处于特殊状态，**它就完全帮不上忙** ——
最典型的是「这首歌已经在「歌」收藏夹里了」：

> 你看到 `累计 93.4s / 需 93s (100%)`，听了十几遍，次数就是不涨，面板上没有任何解释。

现在面板会**在最上面直接写出结论**，不用自己推理。

---

## 主要变化

### 1. 顶部先给结论

只要处于不会计数的状态，第一行就是一句话结论：

| 结论 | 颜色 | 含义 |
|---|---|---|
| `不计数：已在「歌」收藏夹` | 黄 | 符合预期 —— 已收藏就不重复计数、不再弹卡 |
| `不计数：未判定为音乐` | 红 | 去弹窗「标为音乐」即可修正 |
| `不计数：已被你排除` | 黄 | 你手动排除过 |
| `不计数：静音（「静音也计时」已关闭）` | 黄 | 取消静音或改设置 |
| `仅计视频级：合辑不进歌曲榜` | 灰 | 合辑不污染单曲榜 |
| `已计入：有效收听达标` | 绿 | 正常 |

### 2. 新增这些行

- **`收藏`** —— 是否已在收藏夹。`已在「歌」→ 不计数、不提醒`
- **`依据`** —— 判定来自 `后台索引` 还是 `页面收藏按钮`（DOM 更实时）
- **`索引`** —— 索引条数与刷新时间；`不可用`（红）/`已过期`（黄）时说明已降级、可能漏判
- **`上报`** —— 后台的实际返回，如 `✕ 已在收藏夹，跳过计数 · 3 秒前`
- **`已听`** —— 视频级 / 歌曲级的历史次数与阈值进度（`还差 2 次`）
- **`丢弃`** —— ★ 解释**秒数为什么不动**：`拖进度 3 次 · 静音 12.5s · 进度停滞 2 次`，
  下方灰字给出原因（拖动只计入与墙钟相符的部分，防刷进度）
- **`容量`** —— 夹满时提示收藏目标已改为「歌2」
- **`AI`** —— 已应用（含曲名/版本/把握度与理由）/ 调用失败已降级 / 队列中

### 3. 口径不再混淆

旧面板把「本次会话的秒数」叫 `累计`，容易和「听了几次」混起来。现在分开：

- **`本次`** `93s / 需 93s (100%)` —— 本次会话的有效收听
- **`已听`** `视频 7/5 · 歌曲 7/5` —— 历史累计次数（决定何时弹卡）

### 4. 颜色分级

绿 = 正常 · 黄 = 不计数但符合预期 · 红 = 非预期 · 灰 = 纯信息

## 修复

- **已收藏不再静默**：进页面即主动查一次收藏状态（DOM + 索引双重确认），
  不必等播完一轮才间接暴露
- **达标却跳过弹卡，现在有据可查**：面板会显示「已收藏 → 本次跳过 1 张提醒卡」
- **重播后结论误报**：`resetSession` 会清掉会话标志但上一次上报记录仍在，
  导致重播时结论退回「正在上报…」。现在两种来源都看，只要有过成功上报就显示「已计入」

## 内部改动

- `src/hud.js`（新增）—— 面板渲染抽成**纯函数**（无 DOM 依赖），因此可被单元测试直接覆盖
- `test/test-hud.js` —— **65 项**断言：已收藏 / 非音乐 / 已排除 / 静音 / 合辑 /
  索引不可用或过期 / 夹满 / 上报被拒 / AI 降级 / 丢弃统计 / HTML 转义 / 结论优先级
- `test/test-content-hud.js` —— **33 项**断言：在最小 VM 里**真实加载 `src/content.js`**
  （假 DOM + 假 chrome API），因此能抓到「忘了把后台结果接到面板上」这类**接线**问题
- `tools/verify-zip.js`（新增）—— 打包校验：逐条解压做**字节比对** + 包内引用完整性 + 关键文件清单

**验证**：449 项断言全通过（本轮新增 98 项）

## 安装

⚠️ `chrome://extensions/` 的「加载已解压的扩展程序」**只接受文件夹，不接受 `.zip`**。
请先解压，再选择解压出的文件夹。

1. 下载 `bili-music-tracker-v1.3.2.zip` 并**解压**到固定目录
2. 打开 `chrome://extensions/` → 右上角开「**开发者模式**」
3. 点「**加载已解压的扩展程序**」→ 选解压出的文件夹
4. 首次加载会请求 **Cookie** 权限（读 `bili_jct` 以支持一键新建收藏夹），点「允许」

> 升级安装：覆盖同一目录后，在 `chrome://extensions/` 点该扩展的「刷新」按钮即可，数据不会丢。
